About Fake News Detection System

Project Overview

This project is a Machine Learning based application designed to automatically classify news articles as Real or Fake using Natural Language Processing (NLP) techniques and supervised learning algorithms.

Technical Highlights:
  • Dataset: Trained on 6,335 benchmark news articles (Real & Fake balanced dataset).
  • Preprocessing: Regex noise cleaning, lowercasing, stopword filtering, and Porter Stemming.
  • Feature Extraction: TF-IDF Vectorization with unigram and bigram n-grams (1-2).
  • Classifier: Passive-Aggressive Classifier & Logistic Regression.
  • Performance: Achieves 91.55% accuracy on unseen test data.
