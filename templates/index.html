How the System Works

The 3-stage Machine Learning & Natural Language Processing pipeline

1. Text Preprocessing

Removes punctuation, HTML tags, special symbols, and stop-words. Words are stemmed using the Porter Stemmer down to their root meaning.

2. TF-IDF Vectorization

Converts clean text into mathematical features using TF-IDF across unigrams and bigrams, ranking word importance against real vs fake patterns.

3. ML Classification

A high-speed Passive-Aggressive Classifier evaluates the text vector against learned decision boundaries and generates calibrated credibility probabilities.
